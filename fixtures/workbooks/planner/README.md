# Genuine appointment planner

`planner.xlsm` was saved and exported by the existing owned Excel process.
Its original VBA creates SpinButton, ScrollBar, ToggleButton and TabStrip
controls and updates an appointment summary from their events. Static labels
and a Close button exercise supported Office persistence. No source conversion
or event-handler replacement is needed to run the saved application on VM3.

The paired scenarios and exact limits are in
[`oxforms-jbjp.126`](../../../docs/evidence/W010_complete_msforms_object_model_parity/beads/oxforms-jbjp.126/README.md).
The committed sources and genuine FRM/FRX export are pinned with the workbook.
`author_planner.py` refuses to overwrite an existing reviewed fixture.
