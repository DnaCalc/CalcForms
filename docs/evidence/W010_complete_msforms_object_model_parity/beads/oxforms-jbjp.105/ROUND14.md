# Common control properties, TabIndex renumbering and twip geometry (round 14)

Native source: `native-round14.json` (Excel 16.0.20527, one owned hidden Excel on a private desktop, pid recorded in the
file; the guard sampled 4,506 times and saw 0 windows, 0 visible windows and 0 foreground hits on the owner desktop).
`tools/office-oracle/capture_round14_native.py` runs three scripts through one interpreter
(`round14_engine.bas`: `add`, `get`, `let`, `snap`, `remove`, `copyfont`); the scripts are generated by
`round14_scripts.py`. The same interpreter and script lines run against the production controls in
`crates/calcforms-calcvba-adapter/tests/round14_replay.rs`.

## Measured

* Members. Every control has `Tag` (String, default "") and `ControlTipText` (String). `HelpContextID` (Long, default 0)
  and `TabStop` (Boolean, default True) exist on every control except Label and Image; `TabIndex` (Integer) on every
  control except Image. Reading a missing member raises 438.
* Coercions. Tag and ControlTipText take Empty as "" and numbers as their text (`2.5` gives "2.5"); Null raises 13.
  HelpContextID rounds a Double (2.7 gives 3) and parses numeric text; non-numeric text and Null raise 13. TabStop takes
  any non-zero number as True; text that is not a Boolean and Null raise 13.
* TabIndex. A control added to a container gets the next free index among the tab-slot controls (an Image takes none).
  Writing n moves the control to position n among its container's tab-slot controls and renumbers the others (2 to 0 gives
  0,1,3,... shifted up); a value past the last slot goes last (99 gives 12 of 13 slots); a negative value raises 380;
  the same value is quiet; a Double rounds (2.6 gives 3). Frame children and page children number independently of the
  form.
* Geometry. Left, Top, Width and Height are held in twips: a write rounds to the nearest 0.05pt (0.24 gives 0.25, 10.37
  gives 10.35, 33.33 gives 33.35, 100.123 gives 100.1). Left and Top accept negative values; Width and Height raise 380
  for a negative value and keep the old one. Text numbers convert (`"14.5"`), Empty gives 0, Null and non-numeric text
  raise 13, Boolean True gives -1. Large values (1,000,000pt) are kept. A control in a Frame behaves the same.
* UserForm. Width 240, Height 180, InsideWidth 228, InsideHeight 150.75, Zoom 100. Zoom accepts 10 to 400 (a Double
  rounds: 150.5 gives 150) and raises 380 outside. Width and Height round to the twip and have a minimum (102 and 29.25);
  InsideWidth is Width less 12.
* `Controls.Remove "Txt"` raised 13 on this call path (a late-bound string argument); the control stayed. The runtime
  removes it, so that line is listed as a difference.
* A `Controls.Add("Forms.MultiPage.1")` control has two pages (Page1, Page2) natively; the runtime has none until
  `Pages.Add`, so the page-child lines are listed as differences.

## Runtime

Tag, ControlTipText, HelpContextID, TabStop and TabIndex are public members of every control class that has them
natively; `OxControlCore` holds the values and `Controls.MoveTabIndex` renumbers the container. The public Left, Top,
Width and Height setters round to the twip and refuse a negative Width or Height (error 380); internal layout still
writes unrounded values through `Core`.

## Ledger

The UserForm rows `Width`, `Height`, `InsideWidth`, `InsideHeight` and `Zoom` are verified from the typed UserForm
exercise and the geometry script (5 of the 23 rows that moved in this round; the others are the Font rows listed in
`../oxforms-jbjp.101/ROUND14.md`). Tag, ControlTipText, HelpContextID, TabStop and TabIndex are members of the FM20
`IControl` interface; the ledger only projects the default interface of each control, so those 130 new public declarations
(24 TabStop, 26 TabIndex, 28 Tag, 28 ControlTipText, 24 HelpContextID, one per accessor) are counted as unexpected-public
members and cannot become verified there. The native record and the replay show they are real FM20 members; counting them
needs the ledger to project `IControl` onto each coclass, which this round did not attempt.

## Not done

Scrolling (UserForm/Frame ScrollBars, ScrollHeight, ScrollTop and the keep-visible flags) was not measured. The default
size of a control added by `Controls.Add` was measured for the TextBox only (72 by 18, now the runtime default); other kinds
keep a size of 0. Page-child tab order needs the two default pages of a `Controls.Add` MultiPage.
