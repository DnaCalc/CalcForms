# W004 Text Label Oracle Pixels Evidence

This directory holds W004 evidence for text-bearing Excel/MSForms `Label`
oracle captures.

W004 extends the W003 blank rectangle-label oracle by adding a simple caption and
explicit normal font settings. Evidence here should record what real
Excel/MSForms draws: screenshots, metadata, logs, hashes, and pixel facts.

These artifacts are black-box Office/MSForms observations. They are not OxForms
runtime APIs and do not claim OxForms text parity.

## Layout

- `captures/` holds generated live Excel/MSForms capture outputs.
- Later W004 reports may add pixel-fact manifests or summaries beside the
  capture that produced them.
