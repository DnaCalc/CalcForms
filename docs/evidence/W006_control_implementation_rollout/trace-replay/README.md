# W006 Trace Replay Evidence

Status: synthetic host-neutral modal-frame subset for `oxforms-0a0.22`.

This directory holds W006 trace/replay artifacts that extend the W005 trace
contract without claiming live MSForms modal parity.

## Current Artifacts

- [`modal-frame-subset.synthetic.v1.json`](modal-frame-subset.synthetic.v1.json)
  is generated by
  `crates/oxforms-core/examples/w006_modal_frame_trace.rs`. It records a small
  replay-only modal frame sequence: `ShowFormModal`, `EnterModalFrame`,
  synthetic input while the modal frame is active, `PumpFrameExited`,
  `ExitModalFrame`, and the delayed `effect_completed` rows for the modal
  frame effects.

The artifact is synthetic and host-neutral. It does not create live windows, run
Excel/MSForms, execute OxVba, block or resume caller-side VBA, implement
`DoEvents`, or claim nested modal/MSForms parity. Missing live support remains
owned by the PAL/effect-runner and OxVba runtime blockers named in
[`../nested-modal-reentrant-pump-design.md`](../nested-modal-reentrant-pump-design.md).
